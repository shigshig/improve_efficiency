# 翌週タスク入力シート（フォールバック用）

Microsoft 365 との自動連携を行わない場合、または手動でタスクを直接指定したい場合は、以下の表にタスクを記載してエージェントに渡してください。

## 1. 翌週の固定予定（会議・面談など）
| 日時 (例: 月 10:00-11:00) | 予定名 | 備考 |
| :--- | :--- | :--- |
| 月 09:00-09:30 | 週次朝会 | 固定会議 |
| 水 14:00-15:00 | 定例進捗MTG | 固定会議 |

## 2. 翌週実施予定タスク一覧
- **区分**: `MUST`（来週絶対）、`WANT`（できれば来週）、`BACKLOG`（期限なし/余裕タスク）
- **見積時間**: 0.5h単位（30分 = 0.5h, 1時間 = 1.0h, 2時間 = 2.0h）
- **集中度**: `高`（午前中希望・思考力重視）、`低`（午後可・通常/連絡等）
- **分解希望**: `要`（自動でサブタスクに分解して配置）、`不要`（単一タスクのまま配置）

| タスク名 | 見積時間 | 区分 (MUST/WANT/BACKLOG) | 期限 (YYYY-MM-DD) | 集中度 (高/低) | 分解希望 | 備考 (仕上げタスク等) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 四半期営業報告書の作成 | 2.0h | MUST | 2026-11-18 | 高 | 要 | 最終レビューと仕上げ作業を含む |
| 新機能リリース計画ドラフト | 1.5h | MUST | 2026-11-19 | 高 | 要 | 骨子作成〜ドラフト仕上げ |
| A社向け提案資料の修正 | 1.0h | WANT | 2026-11-20 | 低 | 不要 | 先方フィードバック反映 |
| 社内アンケート集計・分析 | 2.5h | WANT | なし | 低 | 要 | 期限未定、空き時間で実施したい |
| 定例メール・連絡対応 (週計) | 2.5h | MUST | 毎日 | 低 | 不要 | 1日30分ずつ配置希望 |
