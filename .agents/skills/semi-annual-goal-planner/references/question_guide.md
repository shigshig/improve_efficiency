# 対話・ヒアリング質問ガイド (Interview & Question Guide)

本ドキュメントは、半期目標設定エージェントがユーザーとの対話の中で必要な情報を引き出すための質問指針・パターン集です。

---

## 1. ヒアリング時の鉄則（エージェント行動規範）

1. **質問攻めの禁止**:
   - 一度の返答で投げる質問は**最大2〜3問**に絞る。一度に大量の質問を列挙してユーザーに負担を与えないこと。
2. **選択肢・目安の提示**:
   - 単に「どうしますか？」と聞くのではなく、「例えばA（金額目標）、B（工数削減目標）のどちらに近いですか？」や「業界標準的には〇〇ですが、いかがでしょう？」のように回答しやすい補助線を引くこと。
3. **前提を踏まえた質問**:
   - 既に提供されている情報（案件名、役職、前期の課題など）を引用し、「前期の振り返りで〇〇とありましたが〜」と文脈を繋げて質問すること。

---

## 2. 観点別・深掘り質問パターン

### ① 担当チームでの売上貢献
| 不足情報・課題 | 質問テンプレート |
| :--- | :--- |
| **目標金額・規模が不明** | 「現在担当されている案件（〇〇）の今期の売上見込み、もしくはチーム全体で目指している売上目標（〇〇万円等）の規模感を把握されていますか？もし不明な場合、『納期内納品による売上確定』や『提案工数削減による利益率改善』を主軸にすることも可能です。」 |
| **個人の役割・寄与度が不明** | 「この案件において、ご自身が売上や利益率に直接インパクトを与えられる領域はどこでしょうか？（例: 納期遵守による検収完了、追加機能のアップセル提案、開発工数の削減など）」 |
| **前期の課題が売上・案件管理にある場合** | 「前期に『〇〇（例: スケジュール遅延、スコープ肥大化）』が課題に挙がっていましたが、今期はその再発防止としてどのような手段（例: 週次マイルストーン管理、仕様変更の事前合意プロセスなど）を取り入れますか？」 |

---

### ② 人材育成
| 不足情報・課題 | 質問テンプレート |
| :--- | :--- |
| **育成対象者が不明** | 「今期、後輩や新メンバーで特に重点的に育成したい対象者（年次や役割）はいらっしゃいますか？もし特定の個人がいない場合は、『チーム全体のコードレビュー品質底上げ』や『ナレッジ共有による属人化解消』を目標に設定できます。」 |
| **達成基準（ゴール）が抽象的** | 「そのメンバーが半期末に『どのような状態になっていれば大成功』と言えるでしょうか？（例: 一人で要件定義〜設計を完結できる、差し戻し率が〇%以下になる、特定のツールを使いこなせるなど）」 |
| **具体的な指導手段が不明** | 「育成のためにどのようなアクションを定期的に実施できそうですか？（例: 週1回の1on1/ペアプロ、設計レビューの同席、業務チェックリストの作成など）」 |

---

### ③ 自社の事業貢献
| 不足情報・課題 | 質問テンプレート |
| :--- | :--- |
| **取り組むテーマが決まっていない** | 「自社組織への貢献として、以下のうち興味がある・または会社から期待されているものはどれに近いでしょうか？<br>1. 業務効率化・自動化ツール（AIやスクリプト）の開発と社内展開<br>2. 社内勉強会の開催や技術ドキュメントの体系化<br>3. 採用活動への協力（カジュアル面談、技術ブログ執筆など）」 |
| **効果測定（定量化）のイメージがない** | 「開発したツールやナレッジを社内展開する場合、どのくらいの規模感をターゲットにしますか？（例: チーム内5名、他部署含め20名、月間計〇〇時間の工数削減など）」 |

---

### ④ 役職定義（昇格要件）とキャリア志向
| 不足情報・課題 | 質問テンプレート |
| :--- | :--- |
| **目指す役職の要件が曖昧** | 「今回目指したい次の役職・グレードで、特に現状とギャップが大きい（会社から求められている）能力要件は何でしょうか？（例: チーム横断の課題解決力、プレイングマネジメント、技術戦略の策定など）」 |
| **キャリアの方向性と目標の乖離** | 「ご自身の今後1〜3年後のキャリア志向（例: マネジメント志向、エキスパート/技術特化、新規事業リードなど）を踏まえ、今回の目標の中で最も注力したいテーマはどれでしょうか？」 |

---

## 3. 会話の進行フロー例

```text
ユーザー: 「半期目標を立てたい。チーム売上は今期2000万目標で、自分は案件Aのリーダーをやる予定。」
↓
エージェント:
1. チーム売上2000万と案件Aのリーダー就任という前提を整理して受け止める。
2. 育成と自社貢献の観点が未入力であることを検知。
3. 2点に絞って質問:
   - 「案件Aチーム内に、今回特に育成・成長させたいメンバーはいらっしゃいますか？」
   - 「自社の事業貢献として、今回の案件で得られる知見の社内展開や、業務ツールの共有などでやってみたい構想はありますか？」
```
